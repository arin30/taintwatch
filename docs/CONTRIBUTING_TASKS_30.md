# Catalog of 30+ Contributor Tasks ("Good First Issue" & "Help Wanted")

This catalog provides 30 curated, well-scoped tasks for community contributors.
To claim a task, open an issue using the [Contributor Task Assignment Template](https://github.com/eyadstein/taintwatch/issues/new?template=good_first_issue.yml) mentioning the Task ID.

---

## Category 1: Framework & Model Integrations

### Task 01: LlamaIndex RAG Document Ingestion Adapter
- **Labels**: `good first issue`, `integrations`
- **Difficulty**: Easy
- **Description**: Add a `TaintwatchLlamaIndexHandler` that hooks into LlamaIndex's node post-processors or query engine, automatically labeling retrieved nodes as `Integrity.UNTRUSTED` with the originating document URL/ID as provenance.
- **Target Files**: `src/taintwatch/integrations/llamaindex.py`, `tests/test_llamaindex.py`
- **Acceptance Criteria**: Unit test verifying retrieved nodes carry `UNTRUSTED` label and propagate to synthesized responses.

### Task 02: AutoGen Conversation Message Interceptor
- **Labels**: `good first issue`, `integrations`
- **Difficulty**: Medium
- **Description**: Create a wrapper for AutoGen's `ConversableAgent` that monitors tool execution calls generated by one agent before passing them to another agent's execution environment.
- **Target Files**: `src/taintwatch/integrations/autogen.py`, `tests/test_autogen.py`
- **Acceptance Criteria**: Verifies that untrusted suggestions from an external agent cannot invoke guarded tools without approval.

### Task 03: CrewAI Custom Tool Security Decorator

- **Target Files**: `src/taintwatch/integrations/crewai.py`, `tests/test_crewai.py`
- **Acceptance Criteria**: Decorated CrewAI tools raise `PolicyViolation` when invoked with tainted strings.

### Task 04: Semantic Kernel Plugin Function Filter
